# markdown/src/main/kotlin/co/anitrend/support/markdown/html/

## Responsibility

Contains custom Markwon HTML tag handlers for alignment syntax in markdown rendered through HtmlPlugin.

## Design

`AlignTagHandler` is a `SimpleTagHandler` that maps `<align>` attributes to Android alignment spans. `CenterTagHandler` is a lower-level `TagHandler` that visits block children and spans the whole `<center>` tag range.

## Flow

HtmlPlugin encounters supported tags, asks the handler for spans or invokes its handler callback, and applies `AlignmentSpan.Standard` to the tag content. `<align center>` maps to centered alignment, `<align end>` maps to opposite alignment, and unrecognized align attributes use normal alignment.

## Integration

Registered by `CorePlugin.configure` against Markwon HtmlPlugin. Used by markup generated by preprocessors and by source markdown that includes supported HTML tags.
