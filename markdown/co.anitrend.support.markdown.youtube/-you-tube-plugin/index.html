YouTubePlugin

class YouTubePlugin : AbstractMarkwonPlugin

Handles AniList's youtube(ID-or-URL) custom syntax for YouTube embeds.

During processMarkdown the syntax is replaced with an <a> tag linking to the video, displaying a YouTube thumbnail image. Relies on HtmlPlugin for rendering.
